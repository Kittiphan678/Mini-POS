# 🧋 Mini POS System (Python CLI)

ระบบขายหน้าร้านขนาดเล็ก (Point of Sale) แบบทำงานผ่าน Command Line พัฒนาด้วยภาษา Python เพื่อจัดการสต็อกสินค้า รับออเดอร์ลูกค้า คำนวณยอดรวม และทอนเงินอย่างครบวงจร

## ✨ ฟีเจอร์หลัก (Features)
* **จัดการฐานข้อมูลสินค้า (Nested Dictionary):** เก็บข้อมูลชื่อเมนู ราคา และจำนวนสต็อกคงเหลือแบบเรียลไทม์
* **ตรวจสอบและตัดสต็อกอัตโนมัติ:** เช็กจำนวนสินค้าคงเหลือก่อนรับออเดอร์ ป้องกันการขายเกินสต็อกจริง
* **ระบบตะกร้าสินค้า (Shopping Cart):** รวบรวมรายการที่ลูกค้าสั่งซ้ำให้อัตโนมัติ พร้อมแสดงจำนวนเมนูและรายการในตะกร้า
* **เมนูควบคุมการทำงาน (Match-Case Navigation):** เลือกสั่งซื้อ (`1`), คิดเงิน (`2`), หรือยกเลิกรายการ (`3`) ได้อย่างเป็นระบบ
* **ออกใบเสร็จและคำนวณเงินทอน:** สรุปรายการสั่งซื้อทั้งหมด ยอดเงินรวมสุทธิ และคำนวณเงินทอนเมื่อรับชำระเงิน

## 🛠️ โครงสร้างข้อมูลและเทคโนโลยีที่ใช้
* **Language:** Python 3.10+ (รองรับคำสั่ง `match-case`)
* **Data Structures:**
  * `Dictionary` (Nested Dictionary สำหรับฐานข้อมูลสินค้า และ Dictionary สำหรับตะกร้าสินค้า)
  * `List` (แปลง `.keys()` และ `.values()` เพื่อแสดงผลรายการในตะกร้า)
* **Control Flow:** `while True`, `match-case`, `if-else`, `for` loop
