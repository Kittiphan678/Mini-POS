# ⚡ MINIPOS.AI — ระบบขายหน้าร้านอัจฉริยะพร้อมสมองกลคิดวิเคราะห์เอง (Smart POS & Autonomous Store Intelligence)

ระบบขายหน้าร้าน (POS) ยุคใหม่ ดีไซน์ High-Tech Cyberpunk Dark Theme สวยงาม ลื่นไหล และมาพร้อมกับ **"ระบบสมองกลคิดวิเคราะห์เอง (Autonomous AI Brain)"** ที่ช่วยให้เจ้าของร้านเห็นทิศทางยอดขาย วิเคราะห์สต็อก วางแผนการสั่งซื้อ และออกแบบโปรโมชั่นเพิ่มกำไรได้แบบอัตโนมัติ

---

## 🌟 ฟีเจอร์เด่นของระบบ

### 🧠 1. ระบบสมองกลคิดวิเคราะห์เอง (Autonomous AI Brain & Analytics)
- **คะแนนสุขภาพธุรกิจ (AI Health Score 0-100)**: ประเมินสุขภาพร้านแบบเรียลไทม์โดยคำนวณจาก อัตรากำไรขั้นต้น (Profit Margin), ความเสี่ยงของขาดสต็อก, และปริมาณบิลขาย
- **สรุปรายงานข้อคิดเห็นจาก AI อัตโนมัติ (Executive Bulletins)**: วิเคราะห์จุดเด่น จุดเสี่ยง เมนูเรือธง และช่วงเวลาขายดีแบบอัตโนมัติ
- **ระบบพยากรณ์เวลาสินค้าจะหมดสต็อก (Stockout Run-Out Predictor)**: คำนวณความเร็วในการขาย (Sales Velocity) และคาดการณ์เวลาที่สินค้าแต่ละชนิดจะหมดสต็อก
- **ระบบแนะนำสั่งซื้อและเติมสต็อกอัจฉริยะ (Smart Reorder Assistant)**: คำนวณปริมาณที่ควรสั่งซื้อเพิ่ม (ROP) พร้อมประมาณการงบประมาณที่ต้องใช้ และมีปุ่ม **"⚡ เติมตามที่ AI แนะนำ"** แบบ 1-Click Restock
- **เมนูเมทริกซ์ (BCG Menu Matrix)**: จัดกลุ่มสินค้าเป็น 4 กลุ่มเชิงกลยุทธ์:
  - ⭐ **Stars (ดาวเด่น)**: ขายดีมาก + กำไรสูง
  - 🐮 **Cash Cows (ทำเงินหลัก)**: ขายได้เรื่อยๆ สม่ำเสมอ
  - ❓ **Question Marks (ดาวรุ่งรอลุ้น)**: กำไรสูงแต่ยอดขายยังน้อย
  - 🐶 **Dogs (สินค้าชะลอตัว)**: ยอดขายน้อย + กำไรต่ำ
- **วิเคราะห์พฤติกรรมการซื้อคู่ (Market Basket Analysis & Bundle Deals)**: ตรวจจับเมนูที่ลูกค้าชอบสั่งคู่กันในบิลเดียว และออกแบบโปรโมชั่นจับคู่ที่ช่วยเพิ่มยอดซื้อต่อบิล (+15% ถึง +25%)
- **กราฟวิเคราะห์แบบ Interactive (Chart.js)**:
  - กราฟแนวโน้มยอดขายตามช่วงเวลา (Hourly Sales Trend)
  - กราฟเปรียบเทียบยอดขายรวมและกำไรสุทธิตามแต่ละเมนู
- **ที่ปรึกษา AI ประจำร้าน (Ask Store AI Chatbot)**: ตอบคำถามเชิงธุรกิจได้แบบเรียลไทม์ เช่น *"เมนูไหนทำกำไรสูงสุด?"*, *"ควรเติมสต็อกอะไรด่วน?"*, *"ช่วยคิดโปรโมชั่นบ่ายหน่อย"* หรือพิมพ์ถามได้อิสระ

### 🛍️ 2. ระบบขายหน้าร้าน (POS Terminal)
- **เมนูสินค้าพร้อมไอคอนและหมวดหมู่**: กรองตามหมวดหมู่ (ชา, กาแฟ, นมสด, เบเกอรี่) หรือพิมพ์ค้นหาในช่อง Search ได้ทันที
- **เลือกระดับความหวานและจำนวน**: ปรับความหวาน 100%, 50%, 25%, 0%
- **ตะกร้าสินค้าสมบูรณ์แบบ**: ปรับเพิ่ม (+), ลด (−) หรือลบรายการในตะกร้าได้อิสระ
- **ระบบโค้ดส่วนลด**:
  - `SALE10`: ลดทันที 10%
  - `MINIPOS`: ส่วนลดพิเศษ 15%
  - `VIP20`: ส่วนลดสมาชิก 20 บาท
- **ช่องทางการชำระเงินที่หลากหลาย**:
  - 💵 **เงินสด**: พร้อมปุ่มกดด่วน (พอดี, 50, 100, 500, 1000) และคำนวณเงินทอนอัตโนมัติ
  - 📱 **QR พร้อมเพย์**: ระบบสร้าง Dynamic PromptPay QR Code ตามยอดเงินสุทธิ
  - 💳 **บัตรเครดิต / เงินโอน**
- **ใบเสร็จรับเงิน (Thermal Print Ready)**: แสดงรายละเอียดบิล หมายเลขบิล วันเวลา เงินทอน และกดสั่งพิมพ์ผ่านเครื่องพิมพ์ความร้อนได้ทันที
- **ระบบเสียงตอบสนอง (Synthesized Audio Feedback)**: เสียงคลิก, เสียงเพิ่มของ, เสียงคิดเงินสำเร็จ โดยใช้ Web Audio API 100% ไม่ต้องโหลดไฟล์เสียงภายนอก

### 📦 3. จัดการคลังสินค้า & เมนู (Inventory Management)
- เพิ่มเมนูสินค้าใหม่ พร้อมกำหนดราคาขาย, ต้นทุน, หมวดหมู่ และไอคอน Emoji
- ปรับสต็อกด่วนทันที (+5, +10, −1) ในตาราง
- แก้ไขข้อมูลสินค้าและต้นทุน
- แจ้งเตือนสถานะสต็อก: พร้อมขาย (เขียว), ใกล้หมด (ส้มกระพริบ), สินค้าหมด (แดง)

---

### 📊 4. สรุปยอดขาย & ประวัติบิล (Sales Summary & Reports)
- การ์ดสรุป KPI ทางการเงิน:
  - ยอดขายรวมสุทธิ (Total Revenue)
  - กำไรขั้นต้นสุทธิ (Gross Profit)
  - จำนวนบิลทั้งหมด (Total Orders)
  - จำนวนชิ้น/แก้วที่ขายได้ (Items Sold)
  - ยอดซื้อเฉลี่ยต่อบิล (AOV - Average Order Value)
- ตารางประวัติบิลการขาย ค้นหาย้อนหลังตามเลขบิลและชื่อเมนู
- **ส่งออกข้อมูลเป็น CSV (Export to CSV)** เพื่อเปิดดูใน Microsoft Excel ได้ทันที
- **ปุ่มจำลองข้อมูลทดสอบ (⚡ จำลองข้อมูลทดสอบ 30 บิล)**: สร้างยอดขายสมจริง 30 บิลย้อนหลัง เพื่อทดสอบระบบสมองกล AI ได้ทันที

## 🚀 วิธีการเปิดใช้งาน

### 1. วิธีที่ 1: ดับเบิลคลิกไฟล์ `start_server.bat` (แนะนำและสะดวกที่สุด 🌟)
- ดับเบิลคลิกที่ไฟล์ **`start_server.bat`**
- ระบบจะเริ่มเปิด Backend Server (พร้อมฐานข้อมูล SQLite) และเปิดหน้าเว็บ `http://localhost:8000` ให้ในเบราว์เซอร์ของคุณโดยอัตโนมัติทันที!

### 2. วิธีที่ 2: รันผ่าน Terminal / PowerShell
เปิด Terminal ในโฟลเดอร์โปรเจกต์:
```powershell
cd "d:\VSCODE\PY PROJECT\POS-WEB_Ai-make"
python server.py
```
> หรือหากใช้ Python ใน AppData:
> ```powershell
> & "$env:LOCALAPPDATA\Python\bin\python.exe" server.py
> ```
จากนั้นเปิดเบราว์เซอร์ไปที่: **`http://localhost:8000`**

### 3. วิธีที่ 3: เปิดไฟล์ `index.html` แบบออฟไลน์ (Standalone)
- ดับเบิลคลิกที่ `index.html` เพื่อใช้งานแบบ Standalone ได้เช่นกัน (ระบบจะใช้ LocalStorage สำรองให้อัตโนมัติ)

## 🔌 ระบบ Backend & REST API (SQLite Database)
ระบบ Backend ถูกพัฒนาด้วย **Python Standard Library 100%** (ไม่ต้องติดตั้ง `pip` หรือแพ็กเกจภายนอก)

| Endpoint | Method | คำอธิบายการทำงาน |
|---|---|---|
| `/api/status` | `GET` | ตรวจสอบสถานะการเชื่อมต่อเซิร์ฟเวอร์ และสถิติข้อมูล |
| `/api/products` | `GET` | ดึงรายการสินค้า สต็อกคงเหลือ และยอดขายสะสม |
| `/api/products` | `POST` | เพิ่มสินค้าใหม่ หรือแก้ไขข้อมูลสินค้าลง SQLite |
| `/api/products/delete` | `POST` / `DELETE` | ลบสินค้าออกจากฐานข้อมูล |
| `/api/products/adjust-stock` | `POST` | ปรับสต็อกสินค้าด่วน (+5, +10, -1 หรือกำหนดจำนวน) |
| `/api/checkout` | `POST` | **ชำระเงินและตัดสต็อกสินค้าแบบ ACID Transaction** (ป้องกันสต็อกติดลบ) |
| `/api/orders` | `GET` | ดึงประวัติบิลการขายพร้อมรายการสินค้าในแต่ละบิล |
| `/api/summary` | `GET` | รายงานสรุปผลภาพรวม (ยอดขาย, กำไร, สินค้าขายดี, สต็อกใกล้หมด) |
| `/api/demo-data` | `POST` | จำลองข้อมูลยอดขาย 30 บิล บันทึกลงฐานข้อมูลและตัดสต็อกสมจริง |
| `/api/reset` | `POST` | รีเซ็ตฐานข้อมูลกลับเป็นค่าเริ่มต้น |
